# Financial Market Analytics Dashboard

An Excel-based financial analytics project built using Power Query and a personal financial database. The project analyses financial performance, market performance, earnings expectations, and analyst sentiment across 500+ companies.

## Project Overview

The project contains several analytical dashboards:

### Earnings Surprise Analysis
Analyses earnings results across 500+ companies by comparing reported earnings with analyst estimates. This allows companies to be examined based on whether they beat, met, or missed expectations.

### Stock Universe Analysis
Provides an overview of the broader stock universe using market capitalisation and S&P 500 performance. A heatmap is used to visualise companies across the market based on their relative size and performance.

### Analyst Ratings & Coverage
Tracks analyst ratings and analyst coverage across 500+ companies over time, allowing changes in analyst sentiment and the level of coverage for individual companies to be explored.

### Coca-Cola Financial Dashboard
A detailed financial performance dashboard for The Coca-Cola Company (KO), combining operational, financial, and market-performance data.

## Coca-Cola Dashboard

The Coca-Cola dashboard includes:

- **Financial KPIs:** ROIC, Net Debt/FCF, PEG Ratio and Net Debt/EBITDA
- **Market Performance:** Coca-Cola's performance compared with the S&P 500
- **Revenue:** Quarterly revenue and revenue growth
- **Revenue Mix:** Revenue breakdown across geographical/business segments
- **Operating Income:** Operating income breakdown by segment and by operation
- **Profitability:** Gross margin, operating margin and net profit margin
- **Free Cash Flow:** Quarterly free cash flow and FCF yield
- **Earnings:** EPS and EPS growth
- **Interactive Filters:** Date-based filtering for analysing different periods

## Tools & Technologies

- Microsoft Excel

- Data modelling
- Financial analysis
- Data visualisation

## Data Pipeline

The dashboards are connected to a personal financial database through Power Query. Data is extracted, transformed and loaded into Excel, where it is used to create the analytical tables, KPIs and interactive dashboards.
